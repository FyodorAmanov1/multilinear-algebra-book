# Chapter-opening story illustrations

The twelve chapter scenes were generated with the built-in image generation
tool, using `character-reference.png` as the shared cast and drawing reference.
The intended medium is Victorian pen and ink with fine engraving-style
crosshatching on warm ivory paper.

`art-direction.json` records the common prompt, scene prompts, and image
descriptions. The scene files use the chapter slugs, from `01-vectors.png`
through `12-forms.png`. They are finished raster illustrations; the geometric
teaching diagrams remain in `assets/figures`.

For additional scenes, reuse the reference cast. Keep Alice's face, hair,
hair ribbon, dress, pinafore, striped stockings, shoes, age, and proportions
consistent. Preserve each companion's face, silhouette, and clothing too.
The reference is a character model, not a composition to reproduce.

Both chapter templates place the scene after the chapter title and before
the opening prose. The PDF preserves image proportions and limits height;
the website uses the same complete image with descriptive alt text.
